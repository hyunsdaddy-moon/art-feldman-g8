# 8학년 펠드먼의 비평 4단계 — 감상수업 홈페이지

호치민시한국국제학교 8학년 미술 감상 수행평가 안내 사이트입니다.

| 쪽 | 파일 |
|---|---|
| 공지사항 | `index.html` |
| 학습내용 | `learn.html` |
| 수행평가 기준 | `criteria.html` |
| 일정·결석생 | `schedule.html` |
| 수행평가지 | `sheet.html` |

- 반별 일정과 결석생 기록은 `script.js` 맨 위 `SCHEDULE`, `ABSENT`에서 고칩니다.
- 출제 작품 4점이 정해지면 `learn.html`의 "출제 작품" 칸을 바꿉니다.
- 작품 이미지는 수업 자료로만 사용합니다. 올덴버그·백남준 작품은 저작권이 있습니다.
