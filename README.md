# 8·9학년 감상수업 홈페이지

호치민시한국국제학교 8·9학년 미술 감상 수행평가 안내 사이트입니다.
8학년 감상수업(화론육법, 주색 남색)은 `g8/`, 9학년(4가지 관점, 주색 빨강)은 `g9/`, 이전 8학년 「펠드먼의 비평 4단계」는 맨 위 폴더(공지사항 `g8-index.html`, 메뉴 비활성화)에 있습니다. 두 8학년 쪽은 같은 반 일정·결석생 기록을 함께 씁니다(`script.js` GRADES의 `8`·`8h`).

| 쪽 | 파일 |
|---|---|
| 공지사항 | `g8-index.html` (기본 주소 `index.html`은 9학년 공지사항으로 넘어감) |
| 학습내용 | `learn.html` |
| 수행평가 기준 | `criteria.html` |
| 일정·결석생 | `schedule.html` |
| 수행평가지 | `sheet.html` |

- 반별 일정은 `script.js` 맨 위 `GRADES`(8·9학년)에서 고칩니다. 결석생 기록은 일정 쪽의 「선생님 입력」으로 Supabase에 저장합니다.
- 꼬리말 방문 수는 `결석생기록-Supabase/05-조회수.sql`, `06-조회수-중복방지.sql`을 실행해야 보입니다(한 브라우저 하루 1번).
- 9학년 저장은 Supabase SQL Editor에서 `결석생기록-Supabase/04-9학년.sql`을 한 번 실행해야 됩니다.
- 9학년 감상 작품 4점(11/9 결정): 뭉크 「절규」, 피카소 「게르니카」, 이중섭 「흰 소」, 워홀 「마릴린 두 폭」 — `g9/learn.html`.
- 작품 이미지는 수업 자료로만 사용합니다. 올덴버그·백남준·론 뮤익 작품은 저작권이 있습니다.
